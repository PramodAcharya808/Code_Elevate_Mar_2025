# Core Redux Concepts

`Store` : Central container for all the state.

`State` : Actial data in the store.

`Actions` : Plain JS objects describing "What Happend" (`{type: 'ADD'}`).

`Reducers` : Functions that handle actions and update the state.

`Dispatch` : Sends an action to update the store.

`Selectors` : Read data from the redux store

# Redux Tool Kit Additions

`createSlice()` : reducer + actions

`configureStore()` : Easier store setup
